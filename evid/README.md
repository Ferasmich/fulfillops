# Project evidence

Save the proof requested in the assignment here: test results, race tests, worker recovery, CI artifacts, deployment results and rollout/latency data. See [the checklist](INDEX.md).

Use clear filenames. Include the command needed to repeat a test and a short note about the result when useful. Keep the required failing and corrected runs. Do not record every setup command or create an audit for routine changes.

Design documents stay in `docs/`. Link to them rather than copying them. Keep secrets and personal data out of saved logs and screenshots.

The old setup records under `01-design/` are background only. They are not required presentation material. [Earlier setup index](setup-index.md).
